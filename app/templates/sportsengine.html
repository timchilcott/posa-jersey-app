Configuration

Set these environment variables to enable the integration:

SPORTSENGINE_CLIENT_ID=your-client-id
SPORTSENGINE_CLIENT_SECRET=your-client-secret
SPORTSENGINE_ORG_ID=your-organization-id

Get these values from SportsEngine HQ → Settings → API Integrations
