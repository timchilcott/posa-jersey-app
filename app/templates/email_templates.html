Email Template Editor

Available Placeholders

Use these placeholders in your email templates. They will be replaced with actual values when emails are sent:

  • {player_list} - List of players with jersey numbers and sport (e.g., "Player: John Doe (#5) - Soccer")
  • {sport} - Sport name(s) for this email (e.g., "Soccer" or "Soccer, Basketball" if multiple)
  • {promo_code} - Promotional code (standard confirmation only)
  • {uniform_url} - Link to uniform ordering site

Note: If no template is found in the database, the system will use built-in default templates. Only the most recently registered sport for each player will be included in the email.
